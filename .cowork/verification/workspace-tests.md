## 涵蓋範圍（57 個，全部可重現、不連外部服務）
- API 契約：目標環境／載入器驗證、相容性規則、分頁、依賴種類、網址主機檢查。
- 儲存：SQLite 版本建立與重開；拒絕較新版本與非本程式資料庫且不改檔；備份、遷移、遷移失敗回滾；v1 → v2 保留插件紀錄、時間設未知；損毀資料庫保持原狀；Sol JSON 一次匯入且原檔不變；注入中繼資料寫入失敗後回滾；程序鎖；只解除管理不刪檔；不安全或保留名稱；符號連結（Unix）。
- 下載：截斷、雜湊不符、偽裝成 JAR 的 HTML、轉址、暫存檔清理。
- 交易：安裝／更新與備份、保留停用狀態、拒絕過期掃描結果；安裝／停用／移除時中繼資料失敗回滾；匯入檔名衝突；可回復移除；上次更新／上次檢查時間（安裝、檢查成功、檢查失敗、未知檔案用修改時間）。
- 身分：雜湊綁定清單、改名檔案身分、精確雜湊辨識。
- 依賴規劃：必要／選用順序、循環、版本衝突、宣告不相容、必要依賴被停用、缺少依賴、網站手動依賴、未驗證相容需確認、已驗證不相容拒絕。
- 更新：發布 ID 與時間比較、防止降級、個別失敗列入報告。
- 匯出：ZIP 只含插件與 manifest、shell 跳脫、腳本固定版本、手動上傳說明。
- 環境清單快取：不編造預設值、重用、離線用舊資料、重啟後保留。
- 圖片快取：合併請求、跨實例磁碟快取、清理隔離、只刪自己的檔案、無效內容、停用、LRU；PNG／GIF／BMP／WebP 有限制的解碼與記憶體淘汰。
- Provider：Modrinth（搜尋、環境、版本、雜湊辨識、網址）；Hangar（搜尋、分頁、平台、相容性、頻道、SHA-256、外部下載、手動依賴、指定版本、網址）。
- 應用層：探索清單去重與結束、設定遷移、欄位正規化；翻譯 key 與佔位符一致、引用的 key 存在；headless Controller 流程（建立實例、預設瀏覽、失敗重試、續頁、清單結束、版本、安裝規劃、網址解析、確認後解除管理保留檔案、第二程序被鎖、欄位隱藏／寬度／重設且不能全隱藏）。
