# 尚未驗證與已知限制

- 只在本機 Windows 實際操作過；Ubuntu CI 通過，macOS CI 修正後待重跑。
- 原生視窗的滑鼠與鍵盤操作沒有自動化；離線擷取送出的事件與介面使用相同回呼。
- 沒有啟動 Minecraft 伺服器；插件實際執行行為由管理者負責。
- 一次安裝多個插件是一連串個別交易，後面失敗時已完成的依賴保留；取代檔案途中斷電需從 `.spa-backups/` 手動復原。
- macOS／Linux 上，上層路徑含系統符號連結的伺服器目錄或 `--data-dir` 會被拒絕（使用者決定維持）。
- 尚未支援：ZIP 匯入精靈、需要私人憑證的付費插件下載、執行期載入 provider、程式自動更新。
