# 驗證紀錄

> 最後修改：2026-11-07 ｜ 基於 commit：`1fe507b`

環境：Windows 11、Rust 1.99.1、Slint 1.18.1。每次驗證都執行 `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings` 與 `cargo test --workspace`。重新執行方式見 [開發說明](PROJECT-DEV.md#測試)。

## 測試涵蓋範圍

目前 57 個測試，全部可重現、不依賴外部服務：

- **API 契約**：目標環境／載入器驗證、相容性規則、分頁、依賴種類、網址主機檢查。
- **儲存**：
  - SQLite 存檔版本的建立與重新開啟。
  - 拒絕較新版本與非本程式的資料庫，且不修改檔案。
  - 備份、遷移，以及遷移失敗時回滾；v1 → v2 遷移保留插件紀錄並把時間設為未知。
  - 損毀的資料庫保持原狀。
  - Sol JSON（實例、插件清單、設定、環境）一次匯入，且原檔不變。
  - 注入中繼資料寫入失敗後回滾。
  - 程序鎖、只解除管理不刪檔、不安全或保留的名稱、符號連結（Unix）。
- **下載**：截斷的內容、雜湊不符、偽裝成 JAR 的 HTML、轉址、暫存檔清理。
- **交易**：
  - 安裝／更新與備份、保留停用狀態、拒絕過期的掃描結果。
  - 安裝、停用、移除時中繼資料寫入失敗會回滾。
  - 匯入檔名衝突、可回復的移除。
  - 安裝、檢查成功與檢查失敗時的上次更新／上次檢查時間；未知檔案使用修改時間。
- **身分**：以雜湊綁定的插件清單、改名檔案的身分、精確雜湊辨識。
- **依賴規劃**：必要／選用依賴的順序、循環、版本衝突、宣告不相容、必要依賴被停用、缺少依賴、網站手動依賴、未驗證相容性需確認、已驗證但不相容時拒絕。
- **更新**：依發布 ID 與時間比較、防止降級、個別失敗列入報告。
- **匯出**：ZIP 只含插件與 manifest、shell 跳脫、腳本固定版本、手動上傳說明。
- **環境清單快取**：不自行編造預設值、重用、離線時使用舊資料、重新啟動後保留。
- **圖片快取**：合併請求、跨實例重用磁碟快取、下載中清理的隔離、只刪除自己的檔案、無效內容、停用狀態、LRU 淘汰；PNG／GIF／BMP／WebP 有限制的解碼與記憶體快取淘汰。
- **Provider**：
  - Modrinth：搜尋、環境清單、版本、雜湊辨識、網址。
  - Hangar：搜尋、分頁、平台、相容性、頻道、SHA-256、外部下載、手動依賴、指定版本、網址。
- **應用層**：
  - 探索清單去重與結束條件、設定遷移、表格欄位正規化。
  - 翻譯檔 key 與佔位符一致，介面與來源引用的 key 都存在。
  - headless Controller 流程：建立實例、預設瀏覽、失敗頁重試、去重的續頁、清單結束、檢視版本、安裝規劃、網址解析、確認後解除管理且保留檔案、第二個程序被鎖擋下、欄位隱藏／調整寬度／重設且不能全部隱藏。

## 尚未驗證

- 只在本機 Windows 測試過；Linux／macOS 的 CI 已設定但尚未執行。
- 原生視窗的滑鼠與鍵盤操作沒有自動化；離線擷取送出的事件與介面使用相同的回呼。
- 沒有啟動 Minecraft 伺服器；插件實際執行時的行為由管理者負責。
- 一次安裝多個插件是一連串個別交易，後面的項目失敗時已完成的依賴會保留。取代檔案途中突然斷電，需要從 `.spa-backups/` 手動復原。
- 尚未支援：ZIP 匯入精靈、需要私人憑證的付費插件下載、執行期載入 provider、程式自動更新。
